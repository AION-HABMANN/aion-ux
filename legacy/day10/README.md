# AION UX · Day 10 — Intelligent Interfaces & AI-assisted UX

Learning materials for Day 10 of the AION UX class: how AI shows up in interfaces, and how to judge it
with three lenses — **transparency** (can the user see why?), **control** (can the user change it?) and
**recoverability** (if it goes wrong, can it be undone?).
